OST 마추기 멀티플레이 v1

[실행]
1. Node.js LTS 설치: https://nodejs.org/
2. 게임실행.bat 더블클릭 (첫 실행 시 npm 패키지 설치를 위해 인터넷 필요)
3. 브라우저에서 http://localhost:3000 접속
4. 닉네임 입력 → 방 만들기 → 문제 추가 → 게임 시작
5. 다른 사람은 같은 서버 주소에 접속 → 방 코드 입력

[접속]
같은 컴퓨터: http://localhost:3000
같은 와이파이: http://방장컴퓨터의-로컬-IP:3000
서로 다른 집: 서버를 인터넷에 배포하거나 안전한 네트워크 연결이 필요합니다.
단순히 localhost 주소를 보내면 친구가 접속할 수 없습니다.

[규칙]
45초 공통 제한, 25초 힌트, 작품명 최초 정답 +1점,
보너스 최초 정답 +1점, F2 스킵 투표, 과반수 찬성 시 정답 공개.
정답 공개 화면에서 영상이 보이고 방장이 다음 문제를 진행합니다.

[참고]
영상은 유튜브 정책에 따라 숨김 재생이 차단될 수 있습니다.
문제 편집 데이터는 방장 브라우저 localStorage에 저장됩니다.
JSON 백업을 권장합니다. 채팅은 서버 메모리에서만 관리됩니다.
이 버전은 소규모 친구 방용 시제품이며, 인터넷 공개 운영에는
계정/접속 보호, 신고·차단, 운영자 관리 등의 추가 기능이 필요합니다.
